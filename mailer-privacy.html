Mailer privacy notice

Updated November 1, 2026. This notice describes BarberCo Mailer, the shop's Gmail sending integration.

Google access

The operator authorizes the shop's designated Gmail account using OAuth. BarberCo Mailer requests only permission to send email on that account's behalf. It does not request inbox-reading, mailbox-search, contacts, or Google Drive permissions. Customers are not asked to authorize their Google accounts.

Information used

The backend uses the recipient email address, message subject and body, and an authorization token to send requested verification and reset codes and appointment notifications. Messages can contain account or appointment information. Google processes the message for delivery. The application uses Render for backend hosting and MongoDB Atlas for account and booking data.

Storage and protection

The sender's OAuth credentials are stored as server-side secrets, not in the public website code. Local recovery copies are encrypted using Windows account protection. Account verification and reset codes are stored as hashes with a ten-minute expiry. The mailer does not use Google data for advertising or sell it.

Access and revocation

The sender operator can revoke BarberCo Mailer's access in the Google Account's third-party connections settings. Revocation stops future Gmail API sending until access is authorized again; it does not recall messages already sent. Google and recipients may retain delivered messages under their own settings. Contact the shop to request assistance with account data or deletion; no automatic deletion deadline is promised by this notice.
